
# MultiVendorPlatform

A multi-vendor e-commerce and on-demand services mobile application.

## Project Structure

- mobile/ - React Native Expo mobile application
- server/ - Node.js and Express backend
- database/ - SQL database scripts

## Planned Features

- Buyer registration and login
- Seller registration and product management
- Service provider registration
- Product marketplace
- Online auctions and live bidding
- Shopping cart and order management
- Service booking
- Payment integration
- Courier GPS tracking
- Monthly subscriptions

## Technology Stack

- React Native
- Expo
- Node.js
- Express.js
- Supabase
- PostgreSQL
